# REM Launcher

**REM Launcher** — приложение для установки и запуска игр из локальных источников.  
Работает с торрент-файлами и опциональными модификациями (фиксами). Не требует подключения к внешним серверам, все данные хранятся локально.

---

## Основные функции

- **Библиотека** — список добавленных игр с указанием статуса установки.
- **Магазин** — отображение доступных игр в виде карточек с возможностью поиска и фильтрации.
- **Установка** — запуск загрузки по торрент-файлу, автоматическое применение фиксов.
- **Запуск** — прямой запуск установленной игры через исполняемый файл.
- **Обновление** — проверка новой версии на GitHub и автообновление лаунчера.
- **Настройки** — выбор темы, языка, поведения при закрытии и автозагрузки.

│ │ icon.png
│ └───fix/
│ └───...
├───storage/
│ ├───downloads/
│ └───installed/
└───database/
rem.db

text

- `games` — каталог с игровыми данными (торренты, метаинформация, фиксы).
- `storage/downloads` — временные файлы загрузок.
- `storage/installed` — установленные игры.
- `database` — SQLite-база с настройками и состоянием установок.

## Добавление игры

1. Создать подкаталог в `games` (например, `games/123/`).
2. Поместить в него `data.torrent` и `info.json`.
3. (Опционально) добавить подкаталог `fix` с файлами модификации.
4. Перезапустить лаунчер или обновить библиотеку.

Пример `info.json`:

```json
{
  "title": "Название игры",
  "description": "Описание",
  "genre": "Action",
  "size_mb": 10240,
  "icon": "icon.png"
}
